**Chapter 6 - Interference**

## Portent
  Logical linear western thought. If *a* allows *c*, and *b* allows *c*, then *a and b* allows *c*.
  What could be more natural, more obvious, it's simple logic - commonsense demands this conclusion. 
  And it works - in classical systems.
  Not so much in quantum ones.
  The problem is not interference, that is a well understood wave phenomena.
  The problem is *destructive interference*.
  Two is not always better than one - sometimes its zero.

## Significance
  Destructive interference is a clean concept for waves, not so for particles.
  That multiple options are not additive is a deep feature of quantum systems.
  We have no good examples in everyday life, at the classical level, classical logic works.
  But to build intuition, we need examples at an accessible level.
  This is where games will enter the story, we can create rules which display destructive interference.
