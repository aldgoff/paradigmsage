# Setup Spec
  Create board, trays, and pieces.

## 1. Purpose
  Support both games (std starting position) and puzzles (manually create an initial position).

## 2. Arch
  Standard panel dispatch with handle functions.

## 3. Buttons
 ### 3.1 List
  - Make Board
  - Place Piece
  - Return
  - Freeze
  - Starting Position
  - Play
 ### 3.2 Ergonomics
  Buttons enabled only when applicable.

## 4. Options
  - Three board sizes
  - Two tray types.
