# GoatCounter (Open Source) Hosted
  1. Create GoatCounter account and site → 15 min
  2. Copy site code (domain identifier) → 2 min
  3. Add GoatCounter <script> to Hugo head.html partial → 10 min
  4. Commit and deploy to GitHub Pages → 5 min
  5. Load site and confirm pageviews increment → 5 min
  6. Decide PDF classification rule (Ch* = chapter, PD* = discourse) → 5 min
  7. Add data-goatcounter-click="pdf_chapter_open" to chapter PDF links → 15 min
  8. Add data-goatcounter-click="pdf_discourse_open" to discourse PDF links → 15 min
  9. Click several PDFs and verify both event counters increment → 10 min
  10. Write down your engagement definition (e.g. “PDF open = serious”) → 5 min
  11. Snapshot baseline stats (note or screenshot) → 5 min
